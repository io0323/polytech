# Java 言語プログラミング スタディノート

組込み機器そのものは C で書くことが多い一方、機器から集めたデータを受け取るサーバ、管理画面、Android アプリなどでは Java がよく使われます。このノートは、C を学んだ人が Java の考え方（オブジェクト指向・例外・スレッド・テスト）を押さえるための入口です。

## 学習順

| 順番 | ノート | 主にできるようになること |
| --- | --- | --- |
| 1 | [01 基本構文](01_basic_syntax/README.md) | 型、制御文、配列、文字列、メソッド、例外を C との違いを意識して書く |
| 2 | [02 オブジェクト指向プログラミング](02_object_oriented/README.md) | クラス、カプセル化、継承、ポリモーフィズム、インタフェース、コレクションを使い分ける |
| 3 | [03 スレッド](03_threads/README.md) | スレッドの作成、排他制御、スレッドプール、並行処理の落とし穴を説明する |
| 4 | [04 テスト技法](04_testing/README.md) | 同値分割・境界値分析などでテストケースを設計し、JUnit で自動テストを書く |

講義の紹介順は「基本構文 → スレッド → オブジェクト指向 → テスト技法」ですが、スレッドはクラスやインタフェースを使うため、このノートではオブジェクト指向を先に置いています。

## 環境

- JDK 17 以降（LTS 版の 17 / 21 / 25 を推奨）。macOS は `brew install openjdk@21`、Ubuntu は `sudo apt install openjdk-21-jdk`。
- 1 ファイルのプログラムは、コンパイルせずに `java Hello.java` で直接実行できます（Java 11 以降）。

```sh
javac Hello.java   # Hello.class が作られる
java Hello         # 実行
```

各ノート末尾の「セルフチェック」に答えられない項目があれば、その節に戻ります。コード例は値を変えて実行し、結果がどう変わるかを確かめてください。
