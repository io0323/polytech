# 電子回路スタディノート

マイコンを使う組込み開発では、C のコードだけでなく「その 0/1 はどの電圧か」「周辺回路は何をしているか」を読めることが重要です。このノートは、回路を設計するための完全な教科書ではなく、デバイスソフトエンジニアが回路図・データシート・デバッガの表示をつなげるための入口です。

## 学習順

| 順番 | ノート | 主にできるようになること |
| --- | --- | --- |
| 1 | [01 電気理論](01_electrical_theory/README.md) | 電圧、電流、抵抗、コンデンサを数式と実機で結び付ける |
| 2 | [02 デジタル回路](02_digital_circuits/README.md) | 論理表、プルアップ、フリップフロップ、タイミングを読む |
| 3 | [03 マイコンのしくみ](03_microcontroller_fundamentals/README.md) | CPU・メモリ・周辺回路・割り込みの関係を説明する |
| 4 | [04 アセンブラ](04_assembler/README.md) | C が命令列になる流れと、逆アセンブルの基本を追う |

## 進め方

1. 数式や論理表をノートに写すだけで終わらせず、値を変えて自分で計算する。
2. マイコンのデータシートでは、GPIO の電気的特性、リセット回路、クロック、割り込みの章を対応付けて読む。
3. C の `volatile` な周辺レジスタをデバッガで観察し、最後に逆アセンブル表示で確認する。

各ノート末尾の「セルフチェック」に、説明できない項目が残ったらその節に戻ります。実機では、電源を切った状態で配線を確認してから通電し、電圧範囲と極性を必ず確認してください。
