# 01. 電気理論 — 回路とコードの共通言語

組込みソフトウェアは電気的な制約の上にあります。GPIO を `1` にしても、電源電圧、負荷、配線、入力しきい値が合わなければ期待どおりには動きません。まず単位と基本法則を身に付けます。

## 1. 基本量と単位

| 量 | 記号 | 単位 | 意味 |
| --- | --- | --- | --- |
| 電圧 | `V` | V（ボルト） | 2 点間の電位差。電流を動かす駆動力 |
| 電流 | `I` | A（アンペア） | 電荷の流れ。`1 mA = 0.001 A` |
| 抵抗 | `R` | Ω（オーム） | 電流の流れにくさ |
| 電力 | `P` | W（ワット） | 消費・供給されるエネルギーの速さ |
| 電荷 | `Q` | C（クーロン） | たまった電気量 |
| 静電容量 | `C` | F（ファラド） | 電荷をためる能力。実務では µF、nF、pF が多い |

接頭辞は `k = 10³`、`M = 10⁶`、`m = 10⁻³`、`µ = 10⁻⁶`、`n = 10⁻⁹` です。`m`（ミリ）と `M`（メガ）は大文字・小文字で別物です。

## 2. オームの法則と電力

```text
V = I × R          I = V / R          R = V / I
P = V × I = I²R = V² / R
```

例: `3.3 V` の GPIO に `1 kΩ` を介して LED をつなぎ、LED の順方向電圧を `2.0 V` と近似します。

```text
3.3 V ──[ 1 kΩ ]──|>|── GND
                  LED

I ≈ (3.3 - 2.0) / 1000 = 1.3 mA
```

抵抗なしで LED や外部回路を GPIO に直結すると、許容電流を超えて GPIO や部品を壊すことがあります。実際の抵抗値は LED の定格、GPIO の source/sink 電流、明るさをデータシートで確認して選びます。

## 3. 直列・並列とキルヒホッフの法則

```text
直列:  V ──[R1]──[R2]── GND     並列:  V ──┬──[R1]──┬── GND
                                           └──[R2]──┘
```

| 接続 | 同じになる量 | 合成抵抗 | 実務での見方 |
| --- | --- | --- | --- |
| 直列 | 電流 | `R = R1 + R2 + ...` | 抵抗分圧、電流制限 |
| 並列 | 電圧 | `1/R = 1/R1 + 1/R2 + ...` | 複数の負荷、プルアップと別経路 |

- **KCL（電流則）**: ある接点に流れ込む電流の和と、流れ出る電流の和は等しい。
- **KVL（電圧則）**: 閉じた経路で電圧の上昇・降下を合計すると 0 になる。

抵抗分圧は、上側を `R1`、下側を `R2` としたとき `Vout = Vin × R2 / (R1 + R2)` です。ただし、`Vout` に接続する入力が電流を取るとこの式どおりになりません。ADC の入力インピーダンスやセンサの出力抵抗も回路の一部です。

## 4. コンデンサと時間変化

コンデンサは直流をため、電圧の急な変化を抑えます。

```text
Q = C × V              i = C × dv/dt
時定数 τ = R × C
```

RC 回路の充電は約 `1τ` で 63.2%、`3τ` で 95%、`5τ` で 99% に達します。たとえば `R = 10 kΩ`、`C = 0.1 µF` なら `τ = 1 ms` です。

| 用途 | 何をするか | 組込みでの例 |
| --- | --- | --- |
| デカップリング | 瞬間的な電流を近くで補い、電源ノイズを逃がす | MCU の電源ピン近くの `0.1 µF` |
| RC フィルタ | 変化をなだらかにする | ボタンのチャタリング、ADC 入力のノイズ低減 |
| 電源保持 | 電圧低下を緩やかにする | リセット時の安定化 |

極性のある電解コンデンサは逆接続が危険です。容量だけでなく耐圧、極性、温度特性も確認します。

## 5. 組込み開発での観察ポイント

- **GND は基準点**です。測定器の GND と基板の GND を正しく共有しないと、電圧は解釈できません。
- MCU の `3.3 V` 入力に `5 V` 信号を入れてよいとは限りません。絶対最大定格と入力しきい値を確認します。
- 「USB 接続時だけ動く」は、電源品質、GND、プルアップ、未接続入力（フローティング）を疑う出発点になります。
- デジタルテスタは平均的な値を見る道具です。短いノイズやクロック波形はオシロスコープ／ロジックアナライザで観察します。

## セルフチェック

1. `5 V` と `2 kΩ` の抵抗なら、電流はいくつか。
2. `10 kΩ` と `10 kΩ` で `3.3 V` を分圧すると、無負荷の `Vout` はいくつか。
3. 直列回路で一定なのは電圧と電流のどちらか。
4. `10 kΩ` と `0.1 µF` の時定数はいくつか。

<details>
<summary>答え</summary>

1. `I = 5 / 2000 = 2.5 mA`。  
2. `1.65 V`。ただし負荷があれば変わる。  
3. 電流。  
4. `τ = 10,000 × 0.1 × 10⁻⁶ = 1 ms`。
</details>
