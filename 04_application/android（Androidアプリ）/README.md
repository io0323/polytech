# Android アプリ スタディノート

IoT 機器の多くは、スマートフォンのアプリから設定・操作・監視します。このノートは、Java の知識を土台に Android アプリの仕組みを理解し、最終的に BLE（Bluetooth Low Energy）で機器を制御するアプリを作れるようになるための入口です。

## 学習順

| 順番 | ノート | 主にできるようになること |
| --- | --- | --- |
| 1 | [01 ユーザインタフェース](01_user_interface/README.md) | プロジェクト構成、Activity とライフサイクル、レイアウトと主なウィジェット、リソースを理解する |
| 2 | [02 イベント処理](02_event_handling/README.md) | クリック・入力・タッチなどのイベントを受け取り、UI スレッドをふさがずに処理する |
| 3 | [03 インテント](03_intents/README.md) | 画面遷移、データの受け渡し、他のアプリの呼び出し、パーミッションを扱う |
| 4 | [04 BLE アプリによるデバイス制御](04_ble_device_control/README.md) | GATT の構造を理解し、スキャン・接続・読み書き・通知を実装する |
| 5 | [05 アプリ開発演習](05_app_development_exercise/README.md) | 要件定義から設計・実装・テストまで、BLE センサモニタを題材に一通り進める |

## 環境

- **Android Studio**（最新の安定版）。SDK・エミュレータ・ビルドツール（Gradle）が一式入ります。
- 言語は **Java** と **Kotlin** のどちらでも書けます。このノートは講義の流れに合わせて Java で書き、Kotlin の書き方は必要に応じて補足します。
- 画面は **XML レイアウト（View）** で作ります。新しい方式の **Jetpack Compose** は 01 で概要だけ紹介します。
- BLE はエミュレータでは基本的に試せないため、**実機の Android 端末**を用意します。

各ノート末尾の「セルフチェック」に答えられない項目があれば、その節に戻ります。[Java スタディノート](../../01_fundamentals/java（Java言語）/README.md)（特にインタフェース、ラムダ式、スレッド）を先に押さえておくと読みやすくなります。
