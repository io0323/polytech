# Linux・ネットワーク スタディノート

IoT 機器は「センサを読む」だけでなく、Linux 上で動き、ネットワーク越しにデータを送り、遠隔から保守されます。このノートは、デバイスソフトエンジニアが Linux とネットワークの用語・コマンド・設定ファイルを読み、実機で確認できるようになるための入口です。

## 学習順

| 順番 | ノート | 主にできるようになること |
| --- | --- | --- |
| 1 | [01 ネットワーク技術](01_network_technology/README.md) | OSI/TCP/IP の階層、IP アドレスとサブネット、TCP/UDP、主要プロトコルを説明する |
| 2 | [02 LAN 構築](02_lan_setup/README.md) | スイッチ・ルータ・DHCP・DNS の役割を理解し、小さな LAN を設計・確認する |
| 3 | [03 Linux の概要とコマンド](03_linux_overview_commands/README.md) | ディレクトリ構成、権限、プロセス、パッケージ、基本コマンドを使いこなす |
| 4 | [04 組込み Linux プログラム](04_embedded_linux_programming/README.md) | クロスコンパイル、デバイスファイル、GPIO/I2C、systemd での常駐化を理解する |
| 5 | [05 Raspberry Pi](05_raspberry_pi/README.md) | OS 導入、SSH 接続、GPIO ピン配置、センサ接続、ネットワーク送信までを一通り行う |

## 進め方

1. ネットワークは「どの層の話か」を常に意識する。トラブル時は下の層（ケーブル・リンク）から順に確認する。
2. Linux コマンドは読むだけで終わらせず、`man` と `--help` で実際にオプションを確かめる。
3. Raspberry Pi を使い、C 言語・電子回路ノートで学んだ GPIO や回路の知識を Linux 上のプログラムとつなげる。

各ノート末尾の「セルフチェック」に答えられない項目があれば、その節に戻ります。`sudo` で実行するコマンドや設定ファイルの変更は、元に戻せるようにバックアップを取ってから行ってください。
