# 03. Linux の概要とコマンド — ターミナルで機器を操る

組込み Linux 機器には画面がないことが多く、SSH でつないでコマンドだけで操作します。Linux の構造と、日常的に使うコマンドを身に付けます。

## 1. Linux の構成

```text
┌──────────────────────────────────────┐
│ アプリケーション（自作プログラム、python3 …） │ ユーザ空間
├──────────────────────────────────────┤
│ シェル（bash）・ライブラリ（glibc）         │
├──────────────────────────────────────┤ ← システムコール
│ カーネル（プロセス・メモリ・ファイル・ドライバ）│ カーネル空間
├──────────────────────────────────────┤
│ ハードウェア（CPU・メモリ・GPIO・NIC）       │
└──────────────────────────────────────┘
```

- **カーネル**: ハードウェアを管理する中核。デバイスドライバもここで動く。
- **シェル**: 入力したコマンドを解釈してプログラムを起動する。標準は `bash`。
- **ディストリビューション**: カーネルにツール群やパッケージ管理を加えた配布形態。Debian 系（Debian、Ubuntu、Raspberry Pi OS）と Red Hat 系（RHEL、Fedora）が代表的。
- Linux では **「すべてはファイル」**。デバイスも `/dev/` 以下のファイルとして読み書きする。

## 2. ディレクトリ構成

| パス | 内容 |
| --- | --- |
| `/` | ルート（最上位） |
| `/home/ユーザ名` | 各ユーザのホーム（`~` と書ける） |
| `/root` | 管理者 root のホーム |
| `/etc` | 設定ファイル |
| `/bin`, `/usr/bin` | 一般コマンド |
| `/sbin`, `/usr/sbin` | 管理用コマンド |
| `/var/log` | ログ |
| `/tmp` | 一時ファイル（再起動で消えることがある） |
| `/dev` | デバイスファイル（`/dev/i2c-1`、`/dev/ttyUSB0` など） |
| `/proc`, `/sys` | カーネルの情報を見せる仮想ファイルシステム |
| `/boot` | カーネルや起動設定 |

パスは `/` から書く **絶対パス** と、現在地から書く **相対パス**（`.` は現在地、`..` は 1 つ上）があります。

## 3. 基本コマンド

| 分類 | コマンド | 意味 |
| --- | --- | --- |
| 移動・表示 | `pwd` / `cd 場所` / `ls -la` | 現在地 / 移動 / 隠しファイル含め詳細表示 |
| 作成・削除 | `mkdir -p a/b` / `touch f` / `rm f` / `rm -r dir` | ディレクトリ作成 / 空ファイル / 削除（ゴミ箱はない） |
| コピー・移動 | `cp a b` / `cp -r d1 d2` / `mv a b` | コピー / ディレクトリごと / 移動・名前変更 |
| 中身を見る | `cat f` / `less f` / `head -n 20 f` / `tail -f f` | 全表示 / ページ送り / 先頭 / 追記を追い続ける |
| 検索 | `grep -rn "語" dir` / `find . -name "*.c"` | 文字列検索 / ファイル名検索 |
| 編集 | `nano f` / `vi f` | テキストエディタ |
| ヘルプ | `man ls` / `ls --help` | マニュアル |

**リダイレクトとパイプ**でコマンドを組み合わせます。

```sh
ls -l > list.txt          # 出力をファイルに書く（上書き）
echo "log" >> app.log     # 追記
make 2> error.txt         # エラー出力（標準エラー）だけを保存
dmesg | grep -i usb       # 前のコマンドの出力を次のコマンドに渡す
```

## 4. ユーザ・権限

```text
-rwxr-xr-- 1 pi gpio 1234 Nov 19 10:00 run.sh
│└┬┘└┬┘└┬┘   │  │
│ │  │  │    │  └ グループ
│ │  │  │    └ 所有者
│ │  │  └ その他: r--  読みのみ
│ │  └ グループ: r-x  読み・実行
│ └ 所有者:   rwx  読み・書き・実行
└ 種類（- ファイル、d ディレクトリ、l シンボリックリンク、c キャラクタデバイス）
```

| 権限 | 数値 | ファイル | ディレクトリ |
| --- | --- | --- | --- |
| `r` | 4 | 読める | 一覧を見られる |
| `w` | 2 | 書ける | 中にファイルを作成・削除できる |
| `x` | 1 | 実行できる | 中に入れる（`cd`） |

```sh
chmod 755 run.sh          # rwxr-xr-x
chmod +x run.sh           # 実行権を付ける
sudo chown pi:pi file     # 所有者とグループを変える
sudo usermod -aG gpio pi  # ユーザ pi を gpio グループに追加（再ログインで反映）
```

`sudo` は管理者権限で 1 回だけ実行する仕組みです。常に `root` で作業すると、誤操作でシステムを壊しやすくなります。

## 5. プロセスとサービス

| コマンド | 意味 |
| --- | --- |
| `ps aux` | 実行中のプロセス一覧 |
| `top` / `htop` | CPU・メモリ使用率をリアルタイムで表示 |
| `kill PID` / `kill -9 PID` | 終了を依頼（SIGTERM）／強制終了（SIGKILL） |
| `コマンド &` / `jobs` / `fg` | バックグラウンド実行 |
| `Ctrl + C` | 実行中のコマンドを中断（SIGINT） |
| `systemctl status ssh` | サービスの状態 |
| `sudo systemctl enable --now ssh` | 自動起動を有効にして今すぐ起動 |
| `journalctl -u ssh -f` | サービスのログを追い続ける |

## 6. パッケージ管理（Debian 系）

```sh
sudo apt update              # パッケージ一覧を最新にする
sudo apt upgrade             # インストール済みを更新する
sudo apt install i2c-tools   # インストール
sudo apt remove パッケージ名  # 削除
apt search キーワード         # 検索
```

## 7. システム情報とネットワーク

| コマンド | 意味 |
| --- | --- |
| `uname -a` | カーネルのバージョン・アーキテクチャ |
| `cat /etc/os-release` | ディストリビューション |
| `df -h` / `du -sh dir` | ディスク空き容量 / ディレクトリの使用量 |
| `free -h` | メモリ |
| `lsusb` / `lsblk` | USB 機器 / ストレージ |
| `dmesg` | カーネルのメッセージ（機器を挿したときの認識など） |
| `ip addr` / `ss -tlnp` | ネットワーク（[01 ネットワーク技術](../01_network_technology/README.md) 参照） |
| `ssh pi@192.168.1.20` | 遠隔ログイン |
| `scp file pi@192.168.1.20:~/` | 遠隔コピー |

## 8. シェルスクリプト

```sh
#!/bin/bash
# 10 秒ごとに CPU 温度を記録する
LOG="$HOME/temp.log"

while true; do
    temp=$(cat /sys/class/thermal/thermal_zone0/temp)
    echo "$(date '+%F %T') $((temp / 1000))℃" >> "$LOG"
    sleep 10
done
```

`chmod +x temp_log.sh` で実行権を付け、`./temp_log.sh` で実行します。変数は `"$VAR"` のように二重引用符で囲むと、空白を含む値でも安全です。

## セルフチェック

1. 設定ファイルとログが置かれる代表的なディレクトリはそれぞれどこか。
2. `chmod 640 file` の結果を `rwx` 形式で書け。
3. コマンドの出力を既存ファイルの末尾に追記する記号は何か。
4. サービスを OS 起動時に自動で起動させるコマンドは何か。
5. USB 機器を挿したときに、カーネルが認識したかを確認するコマンドは何か。

<details>
<summary>答え</summary>

1. 設定は `/etc`、ログは `/var/log`。  
2. `rw-r-----`。  
3. `>>`。  
4. `sudo systemctl enable サービス名`（`--now` で即時起動も）。  
5. `dmesg`（`lsusb` も併用）。
</details>
